# Skills Drop Nation

Skills de Claude para los alumnos de Drop Nation (dropshipping contra entrega).

| Skill | Qué hace |
|---|---|
| `landing-drop-nation` | Pone el nombre, los precios y la imagen principal del producto en Shopify y llena la landing en el tema Drop Nation. |
| `edicion-anuncios-drop-nation` | Escribe los guiones de los anuncios y arma el video. |

Las instala sola la skill **cerebro-drop-nation**, en Claude Code. No hace falta descargar nada a mano.

Instalación manual: copia cada carpeta a `~/.claude/skills/` y abre una sesión nueva.
